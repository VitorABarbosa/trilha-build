# trilha — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Empacotar o Mentingo v4.20.1 com interface em pt-BR em imagens Docker publicadas no GHCR, e operá-lo como a aplicação `trilha` na VPS da FlyingStudio, validado antes na máquina local.

**Architecture:** Dois repositórios. `trilha-build` (esta pasta) clona o upstream numa tag fixa, aplica um overlay (patch git + arquivos novos) e constrói as imagens `trilha-api` e `trilha-web` via GitHub Actions. `POSTIZ_MARKETING/trilha/` guarda o Compose, scripts e docs de operação, seguindo a convenção da VPS.

**Tech Stack:** Docker/Compose, GitHub Actions, GHCR, Node 20 (nas imagens), pnpm 9.15.2 (nas imagens), Caddy, PostgreSQL 16 + pgvector, Redis, MinIO, Resend SMTP.

**Spec:** `docs/superpowers/specs/2026-09-21-trilha-design.md`

```bash
#!/usr/bin/env bash
# Clona o Mentingo na tag fixada em MENTINGO_VERSION para ./upstream (ignorado no git).
# Uso: scripts/upstream.sh [--force]
set -euo pipefail
cd "$(dirname "$0")/.."

TAG="$(tr -d '[:space:]' < MENTINGO_VERSION)"
REPO="https://github.com/Selleo/mentingo.git"

if [ -d upstream ] && [ "${1:-}" != "--force" ]; then
  CUR="$(git -C upstream describe --tags --exact-match 2>/dev/null || echo none)"
  if [ "$CUR" = "$TAG" ]; then
    echo "upstream já em $TAG"; exit 0
  fi
  echo "upstream em $CUR, esperado $TAG; use --force para reclonar"; exit 1
fi

rm -rf upstream
git -c core.longpaths=true clone --depth 1 --branch "$TAG" "$REPO" upstream
git -C upstream config core.longpaths true
# Windows: o checkout inicial pode falhar em caminhos longos; garantir árvore completa.
git -C upstream restore --source=HEAD :/ 2>/dev/null || true
test -f upstream/package.json
test -f upstream/api.Dockerfile
test -f upstream/web.Dockerfile
echo "upstream pronto em $TAG ($(git -C upstream rev-parse --short HEAD))"
```

- [ ] **Step 3: Implementar `util.mjs`**

```js
export function flatten(obj, prefix = "", out = new Map()) {
  for (const [k, v] of Object.entries(obj)) {
    const key = prefix ? `${prefix}.${k}` : k;
    if (v && typeof v === "object" && !Array.isArray(v)) flatten(v, key, out);
    else out.set(key, v);
  }
  return out;
}

export function unflatten(map) {
  const out = {};
  for (const [key, v] of map) {
    const parts = key.split(".");
    let cur = out;
    for (let i = 0; i < parts.length - 1; i++) {
      cur[parts[i]] ??= {};
      cur = cur[parts[i]];
    }
    cur[parts.at(-1)] = v;
  }
  return out;
}

const PH = /\{\{[^}]+\}\}|<\/?[a-zA-Z][^>]*>|\$t\([^)]*\)/g;

export function placeholders(str) {
  return typeof str === "string" ? str.match(PH) ?? [] : [];
}

export function chunk(arr, size) {
  const out = [];
  for (let i = 0; i < arr.length; i += size) out.push(arr.slice(i, i + size));
  return out;
}
```

```js
// Quebra upstream/apps/web/app/locales/en/translation.json em work/i18n/en/NNN.json
// (≤120 strings cada, objeto plano chave->texto). Pedaços já traduzidos em
// work/i18n/pt/NNN.json são mantidos; o script só avisa quais faltam.
import { readFileSync, writeFileSync, mkdirSync, existsSync, readdirSync } from "node:fs";
import { flatten, chunk } from "./util.mjs";

const SRC = "upstream/apps/web/app/locales/en/translation.json";
const OUT = "work/i18n/en";
const SIZE = 120;

const flat = flatten(JSON.parse(readFileSync(SRC, "utf8")));
const parts = chunk([...flat.entries()], SIZE);
mkdirSync(OUT, { recursive: true });
mkdirSync("work/i18n/pt", { recursive: true });
for (const f of existsSync(OUT) ? readdirSync(OUT) : []) if (f.endsWith(".json")) writeFileSync(`${OUT}/${f}`, "");
parts.forEach((p, i) => {
  const name = String(i + 1).padStart(3, "0");
  writeFileSync(`${OUT}/${name}.json`, JSON.stringify(Object.fromEntries(p), null, 2) + "\n");
});
const missing = parts
  .map((_, i) => String(i + 1).padStart(3, "0"))
  .filter((n) => !existsSync(`work/i18n/pt/${n}.json`));
console.log(`${flat.size} strings em ${parts.length} pedaços; faltam traduzir: ${missing.length ? missing.join(" ") : "nenhum"}`);
```

- [ ] **Step 6: `merge.mjs`**

```js
// Lê work/i18n/pt/NNN.json, valida contra o en e escreve o overlay.
// Sai com código 1 se faltar chave, sobrar chave ou placeholder divergir.
import { readFileSync, writeFileSync, mkdirSync, readdirSync } from "node:fs";
import { flatten, unflatten, placeholders } from "./util.mjs";

const EN = "upstream/apps/web/app/locales/en/translation.json";
const OUT = "overlay/apps/web/app/locales/pt/translation.json";

const en = flatten(JSON.parse(readFileSync(EN, "utf8")));
const pt = new Map();
for (const f of readdirSync("work/i18n/pt").filter((f) => f.endsWith(".json")).sort()) {
  for (const [k, v] of Object.entries(JSON.parse(readFileSync(`work/i18n/pt/${f}`, "utf8")))) pt.set(k, v);
}

const errors = [];
for (const [k, v] of en) {
  if (!pt.has(k)) { errors.push(`faltando: ${k}`); continue; }
  const a = placeholders(v).sort().join("|");
  const b = placeholders(pt.get(k)).sort().join("|");
  if (a !== b) errors.push(`placeholder divergente em ${k}: en[${a}] pt[${b}]`);
  if (typeof pt.get(k) !== typeof v) errors.push(`tipo divergente em ${k}`);
}
for (const k of pt.keys()) if (!en.has(k)) errors.push(`sobrando: ${k}`);

if (errors.length) { console.error(errors.join("\n")); console.error(`${errors.length} problema(s)`); process.exit(1); }

const ordered = new Map([...en.keys()].map((k) => [k, pt.get(k)]));
mkdirSync("overlay/apps/web/app/locales/pt", { recursive: true });
writeFileSync(OUT, JSON.stringify(unflatten(ordered), null, 2) + "\n");
console.log(`ok: ${ordered.size} strings em ${OUT}`);
```

- [ ] **Step 1: `scripts/apply-overlay.sh`**

```bash
#!/usr/bin/env bash
# Aplica o overlay pt-BR numa árvore do Mentingo. Uso: scripts/apply-overlay.sh <dir-upstream>
# Falha alto se o upstream mudou de forma que o overlay não encaixa.
set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
DIR="${1:?informe o diretório do upstream}"

cd "$DIR"
for p in "$ROOT"/patches/*.patch; do
  git apply --check "$p"
  git apply "$p"
  echo "patch aplicado: $(basename "$p")"
done

cp -r "$ROOT"/overlay/. .
test -f apps/web/app/locales/pt/translation.json
test -f apps/web/app/assets/svgs/flags/pt-flag.svg

# Cliente gerado e schema swagger: inserir "pt" na união de idiomas.
UNION='"en" | "pl" | "de" | "lt" | "cs" | "es" | "fr"'
N=$(grep -c "$UNION" apps/web/app/api/generated-api.ts || true)
[ "$N" -gt 0 ] || { echo "união de idiomas não encontrada em generated-api.ts"; exit 1; }
sed -i "s/$UNION/$UNION | \"pt\"/g" apps/web/app/api/generated-api.ts
echo "generated-api.ts: $N uniões atualizadas"

node - <<'EOF'
const fs = require("fs");
const f = "apps/api/src/swagger/api-schema.json";
const s = JSON.parse(fs.readFileSync(f, "utf8"));
let n = 0;
const walk = (o) => {
  if (Array.isArray(o)) {
    const consts = o.map((x) => x && x.const);
    if (o.length === 7 && ["en","pl","de","lt","cs","es","fr"].every((l) => consts.includes(l))) {
      o.push({ const: "pt", type: "string" }); n++;
    } else if (o.length === 7 && ["en","pl","de","lt","cs","es","fr"].every((l) => o.includes(l))) {
      o.push("pt"); n++;
    }
    o.forEach(walk);
  } else if (o && typeof o === "object") Object.values(o).forEach(walk);
};
walk(s);
if (n === 0) { console.error("nenhuma enum de idioma em api-schema.json"); process.exit(1); }
fs.writeFileSync(f, JSON.stringify(s, null, 2) + "\n");
console.log(`api-schema.json: ${n} enums atualizadas`);
EOF

grep -q 'PT: "pt"' packages/shared/src/constants/languages.ts
echo "overlay ok"
```

### Task 5: Workflow do GitHub Actions

**Files:**
- Create: `.github/workflows/build.yml`

**Interfaces:**
- Produces no GHCR: `trilha-api:<tag>`, `trilha-web:<tag>-prod`, `trilha-web:<tag>-local`, onde `<tag>` é a tag git sem o `v` inicial (ex.: `4.20.1-pt.1`).

- [ ] **Step 1: Escrever o workflow**

```yaml
name: build
on:
  push:
    tags: ["v*"]
  workflow_dispatch:
    inputs:
      tag:
        description: "Tag de imagem (ex.: 4.20.1-pt.1)"
        required: true

permissions:
  contents: read
  packages: write

env:
  REGISTRY: ghcr.io
  OWNER: vitorabarbosa

jobs:
  meta:
    runs-on: ubuntu-latest
    outputs:
      tag: ${{ steps.t.outputs.tag }}
      upstream: ${{ steps.t.outputs.upstream }}
    steps:
      - uses: actions/checkout@v4
      - id: t
        run: |
          if [ "${{ github.event_name }}" = "workflow_dispatch" ]; then TAG="${{ inputs.tag }}"; else TAG="${GITHUB_REF_NAME#v}"; fi
          echo "tag=$TAG" >> "$GITHUB_OUTPUT"
          echo "upstream=$(tr -d '[:space:]' < MENTINGO_VERSION)" >> "$GITHUB_OUTPUT"

  api:
    needs: meta
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: docker/setup-buildx-action@v3
      - uses: docker/login-action@v3
        with:
          registry: ${{ env.REGISTRY }}
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - uses: docker/build-push-action@v6
        with:
          context: .
          file: build/api.Dockerfile
          push: true
          build-args: MENTINGO_VERSION=${{ needs.meta.outputs.upstream }}
          tags: ${{ env.REGISTRY }}/${{ env.OWNER }}/trilha-api:${{ needs.meta.outputs.tag }}
          cache-from: type=gha,scope=api
          cache-to: type=gha,scope=api,mode=max

  web:
    needs: meta
    runs-on: ubuntu-latest
    strategy:
      matrix:
        include:
          - suffix: prod
            api_url: https://trilha.flyingstudio.com.br
            app_url: https://trilha.flyingstudio.com.br
          - suffix: local
            api_url: http://trilha.localhost
            app_url: http://trilha.localhost
    steps:
      - uses: actions/checkout@v4
      - uses: docker/setup-buildx-action@v3
      - uses: docker/login-action@v3
        with:
          registry: ${{ env.REGISTRY }}
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - uses: docker/build-push-action@v6
        with:
          context: .
          file: build/web.Dockerfile
          push: true
          build-args: |
            MENTINGO_VERSION=${{ needs.meta.outputs.upstream }}
            VITE_API_URL=${{ matrix.api_url }}
            VITE_APP_URL=${{ matrix.app_url }}
          tags: ${{ env.REGISTRY }}/${{ env.OWNER }}/trilha-web:${{ needs.meta.outputs.tag }}-${{ matrix.suffix }}
          cache-from: type=gha,scope=web
          cache-to: type=gha,scope=web,mode=max
```

- [ ] **Step 5: `scripts/backup.sh` e `scripts/restore.sh`**

`backup.sh`:

```bash
#!/usr/bin/env bash
# Backup do trilha: banco, storage (MinIO), uploads da API e .env (contém MASTER_KEY).
# Uso:  ./scripts/backup.sh
# Cron: 0 3 * * * cd /opt/apps/trilha && ./scripts/backup.sh >> backups/backup.log 2>&1
set -euo pipefail
cd "$(dirname "$0")/.."

TS="$(date +%Y%m%d-%H%M%S)"
DIA_SEMANA="$(date +%u)"   # 7 = domingo
DIARIO="backups/diario"
SEMANAL="backups/semanal"
mkdir -p "$DIARIO" "$SEMANAL"
echo "[$(date)] iniciando backup $TS"

docker compose exec -T db pg_dump -U trilha -d trilha --clean --if-exists | gzip > "$DIARIO/db-$TS.sql.gz"

for vol in minio-data uploads; do
  docker run --rm -v "trilha_$vol":/data:ro -v "$(pwd)/$DIARIO":/backup alpine \
    tar czf "/backup/$vol-$TS.tar.gz" -C /data .
done

cp .env "$DIARIO/env-$TS"; chmod 600 "$DIARIO/env-$TS"

if [ "$DIA_SEMANA" = "7" ]; then
  cp "$DIARIO"/*-"$TS"* "$SEMANAL/"
  find "$SEMANAL" -type f -mtime +28 -delete
fi
find "$DIARIO" -type f -mtime +7 -delete
echo "[$(date)] backup $TS concluido"
```

`restore.sh`:

```bash
#!/usr/bin/env bash
# Restaura um backup do trilha. Uso: ./scripts/restore.sh <TS>   (ex.: 20260921-030000)
# Para a API antes, restaura banco + volumes, sobe de novo. Não toca no .env atual.
set -euo pipefail
cd "$(dirname "$0")/.."
TS="${1:?informe o timestamp do backup}"
DIR="backups/diario"; [ -f "$DIR/db-$TS.sql.gz" ] || DIR="backups/semanal"
test -f "$DIR/db-$TS.sql.gz" || { echo "backup $TS não encontrado"; exit 1; }

docker compose stop api web
gunzip -c "$DIR/db-$TS.sql.gz" | docker compose exec -T db psql -U trilha -d trilha -q

docker compose stop minio
for vol in minio-data uploads; do
  docker run --rm -v "trilha_$vol":/data -v "$(pwd)/$DIR":/backup alpine \
    sh -c "rm -rf /data/* /data/..?* /data/.[!.]* 2>/dev/null; tar xzf /backup/$vol-$TS.tar.gz -C /data"
done

docker compose up -d
echo "restaurado $TS; conferir: curl -s -o /dev/null -w '%{http_code}\n' \$PUBLIC_URL/api/healthcheck"
```
